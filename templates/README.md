# Templates

Historical FEAT/FLOBS/PPI/L3 templates are retained for audit, not silently promoted. The old activation FSF has 32 contrasts and malformed neutral/decision vectors and must not define the new pooled model.

The leading pooled candidate is a common full-trial event model with nine partner × feedback conditions and an optional missed-trial nuisance EV. It deliberately omits separate decision regressors because ds003745 does not support equivalent exact phase timing. Outcome/partner contrasts should be derived by contrast name/vector from the authoritative RF1 crosswalk, excluding RF1 decision-only contrasts. This candidate remains gated until event parity and Phase 0 characterization are reviewed.

The ds003745 block rows support a dataset-specific block sensitivity model. A block-level pooled model requires a scientifically defensible RF1 analogue and is not assumed here.
