## Prespecified exploratory tests

Use the **pooled full-trial** family, separately for activation and VS-PPI:

| COPE | Contrast |
|---:|---|
| 10 | Win minus loss across partners |
| 11 | Friend minus stranger, summed over win and loss |
| 12 | Friend minus computer, summed over win and loss |
| 14 | Friend minus stranger in the win-minus-loss contrast |
| 16 | Friend minus computer in the win-minus-loss contrast |

These retain their actual model scaling, not arbitrary averages or percent
signal change. All neutral coefficients are zero. The RF1 phase-resolved
models are a separate estimand and are not used in this pooled analysis.

Each model uses one observation per person: intercept, centered age/10,
dataset indicator, recorded-sex indicators (including O if recorded), and
centered mean FD. FD is weighted by valid FD volumes across **retained runs
only**. No age bins, demographic imputation, silent complete-case deletion,
or subject precision weights are used. Canonical demographics are required;
the historical partial RF1 participant table is never a fallback.

### Whole brain

FSL `randomise`, 5,000 permutations, fixed seed 20261018, TFCE, permutations
restricted within dataset. Both age signs are tested. Each model uses the
intersection of its subject-level FEAT masks; there is no additional smoothing.
Four single-threaded processes run concurrently by default; this is not the
50-worker FEAT launcher and does not use `randomise_parallel`.

FSL's `age_tfce_corrp_tstat*.nii.gz` files encode **1−p**, spatially FWE-corrected
within a signed map. The launcher additionally writes
`age_family_corrp_tstat*.nii.gz`, Bonferroni-adjusted over **20 signed maps**
(five contrasts × two model types × two age signs). Threshold those at ≥.95
for the stated family. The summary reports both correction levels.

This is an equal-subject-weight pooled common-slope analysis, not FLAME and
not precision-weighted by varcopes. Dataset blocks/offsets do not prove
exchangeability or equal residual variances, and one-run subjects have
different precision from two-run subjects. Review those assumptions and
robust/sensitivity models before publication. See the
[official randomise documentation](https://fsl.fmrib.ox.ac.uk/fsl/docs/statistics/randomise.html).

### ROI summaries

Existing provisional masks are selected before inspecting age maps:

- `masks/seed-vs.nii.gz`: activation only. No PPI-within-its-own-seed test.
- `masks/VMPFC-mask-neurovault-resliced-bin.nii.gz`: activation and VS-PPI.

Nearest-neighbor resampling places masks on the common reference grid; no
registration is estimated. Each ROI is intersected with that model's common
coverage mask. The report includes original and common-coverage voxel counts
and fractions; a small fraction limits anatomical interpretation. No extra
subjects are dropped for ROI coverage. These masks' complete provenance and
independence remain provisional, so these are exploratory summaries, not
independent anatomical confirmation.

ROI effects are mean COPE change per decade from OLS with HC3 standard errors,
pointwise 95% t intervals, and Holm correction across **15 two-sided tests**.
The forest plot uses those pointwise intervals, not multiplicity-adjusted
intervals. Activation and PPI units/scales are not directly interchangeable.

## Linux2 execution

The `roi` and `wholebrain` stages can run concurrently with distinct labels.
Each independently audits the retained cohort. `roi` extracts VS activation and
vmPFC activation/PPI and writes the 15-test table and forest plot, without
building merged 4D images or invoking randomise. `wholebrain` runs all ten
activation/PPI models, without ROI tests. `all` retains the combined workflow.
The statistical families and covariates are unchanged across stages.

Use a new label for each attempt. A local `--stage plan` has verified the
358-person demographic/motion design; that does not validate Linux2 image
access. The `all` stage performs the audit before analyses. This command
keeps raw images and participant-level age/sex/ROI tables under ignored
`derivatives/preliminary-age/`; only aggregate reports/provenance and plots
go under `logs/records/preliminary-age/` for Git.

```bash
cd /ZPOOL/data/projects/sharedreward-aging
git pull --ff-only origin main
conda activate sharedreward-phase0
export IMAGING_PYTHON=/ZPOOL/data/tools/anaconda/tug87422/envs/sharedreward-phase0/bin/python
export FSLDIR=/usr/local/fsl
source "$FSLDIR/etc/fslconf/fsl.sh"
export PATH="$FSLDIR/share/fsl/bin:$PATH"

age_batch="age-effects-$(date +%Y%m%d-%H%M%S)"
for age_stage in roi wholebrain; do
  age_label="${age_batch}-${age_stage}"
  nohup setsid -f -w bash code/run_logged.sh \
    --label "$age_label" --include-full-log -- \
    "$IMAGING_PYTHON" code/run_preliminary_age.py \
      --stage "$age_stage" --label "$age_label" --jobs 4 --permutations 5000 \
      --mask-allowance resources/age-mask-allowance-20261018.json \
    > "logs/${age_label}.nohup" 2>&1 < /dev/null &
  printf 'Log: logs/%s.nohup\n' "$age_label"
done
```

Preparation/auditing is initially serial. Once all ten image stacks are ready,
four `randomise` workers start; low initial CPU usage is not evidence of a
failed parallel launcher. Do not start another copy with the same label.

Completion requires `CHECK PASSED` and `completion.json` with `complete: true`.
For `roi`, expect 15 ROI tests and zero finished maps; for `wholebrain`, expect
20 finished maps, zero ROI tests and no failures. `all` produces both.
`plan.json` alone is not a completed run. A provisional completion is not a
resolution of the upstream mask investigation.
If an individual permutation job fails, preserve its output and log for
diagnosis; this is not a reason to rerun L1 or L2.

After completion, commit the run record and this run's aggregate report
directory (not `derivatives/`); push so the maps' summary and ROI plot can be
reviewed here. Full corrected NIfTI maps stay on Linux2. No production imaging
age result has been obtained on the Mac.
